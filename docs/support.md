# Support – SwatchBoard

The Expo display name is SwatchBoard (`app.json`). The npm package name is `collage-maker`.

- General support: https://github.com/Jordan-Ryan/Swatchboard/issues
- Troubleshooting steps:
  - Grant Photos permission when prompted
  - To export, tap Export in the editor; the image saves to the photo library
  - If exports fail on iOS, set Settings > Privacy > Photos > SwatchBoard to Allow

If you need help, open a GitHub issue with your device model and iOS version.
